# warudotech-scripts
Script de automação para instalação do yt-dlp e FFmpeg no Windows de forma segura.

## Como usar
1. Clique no botão **"Code"** (verde) e depois em **"Download ZIP"**.
2. Extraia o arquivo `setup.ps1`.
3. Clique com o botão direito no arquivo e selecione **"Executar com PowerShell"**.
4. Siga as instruções na tela e pronto!

## Por que usar?
- **Segurança:** Instala via Winget (oficial Microsoft).
- **Sem anúncios:** Livre de pop-ups e sites suspeitos.
- **Transparência:** Todo o código é aberto e você pode verificar antes de rodar.
